# Student Assignment Planner

A web-based application designed to help higher-education students organise their academic responsibilities, manage assignments and keep track of important deadlines.

About the Project

The Student Assignment Planner provides students with a simple platform to record assignments, monitor their progress and manage their academic workload.

The application includes a dashboard that displays assignment statistics and a Smart Deadline Tracker that helps students identify upcoming and overdue assignments.

Features

- Dashboard: Displays total, pending and completed assignments.
- Add Assignments: Record assignment names, modules, due dates, priorities, statuses and estimated workloads.
- Edit Assignments: Update existing assignment information.
- Delete Assignments: Remove assignments when they are no longer needed.
- Status Management: Change assignments between Not Started, In Progress and Completed.
- Search:Find assignments using their names or module names.
- Filtering: Filter assignments according to their current status.
- Smart Deadline Tracker:** Identifies overdue assignments, assignments due today and upcoming deadlines.
- Local Storage: Saves assignment information in the browser, allowing data to remain available after refreshing the application.
- Responsive Design: Provides a layout that adapts to different screen sizes.

Getting Started

Requirements

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension for Visual Studio Code (recommended).

Installation

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Locate `index.html`.
4. Right-click the file and select **Open with Live Server**.
5. The application will open in your default browser.

Alternatively, open `index.html` directly in a web browser.

Data Storage

The application uses browser LocalStorage to save assignment information.

This allows users to retain their assignments after refreshing or reopening the application in the same browser.

However, information is stored locally and is not synchronised between different devices or browsers.

Design and Accessibility

The interface uses a warm beige, charcoal and sage-green colour palette to create a clean and organised experience.

The application also considers accessibility through:

- Clearly labelled form fields.
- Keyboard-accessible interface controls.
- Visible keyboard focus indicators.
- Simple navigation and understandable instructions.
- Structured content and readable text.

- Further accessibility and mobile usability improvements.
